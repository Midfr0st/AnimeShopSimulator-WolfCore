# Интеграция с WolfCore

WolfCore предоставляет публичный реестр `WolfCore.WolfModRegistry`. Совместимый мод передаёт объект `WolfModRegistration` со следующими данными:

- уникальный идентификатор;
- отображаемое название и версию;
- краткое описание;
- состояние по умолчанию;
- обработчик включения и выключения;
- функцию отрисовки настроек;
- необязательную страницу игрового терминала.

Страница терминала задаётся через `WolfTerminalPageRegistration`: идентификатор плитки, название, PNG-изображение и обработчики открытия, закрытия и ввода.

Функциональные моды должны корректно отключать свою игровую логику, если WolfCore отсутствует, вместо частичного запуска.
