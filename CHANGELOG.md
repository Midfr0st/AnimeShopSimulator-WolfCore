# История изменений

## Проверка на игре 1.0.74 — 2026-10-20

Версия 0.2.6 сохранена; код и DLL не изменились. Проверены сборка на библиотеках 1.0.74, загрузка ядра и разрешение прямых обращений к игровому API.

Обновлены README и сведения в выпуске. Для совместного использования с фильтрами полок требуется [0.10.5](https://github.com/Midfr0st/AnimeShopSimulator-ShelfFilters/releases/tag/v0.10.5). [Результаты общей проверки](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore/blob/main/docs/COMPATIBILITY-1.0.74.ru.md).

## 0.2.6 — 2026-10-03

Совместимость с Anime Shop Simulator 1.0.7.

- Исправлена работа дополнительных плиток с новым устройством терминала в Anime Shop Simulator 1.0.7: картинки больше не перекрывают подписи, плитки снова нажимаются.
- Переключатель экранов скрывается в разделе «Сотрудники» и других открытых разделах. Переключение доступно только в главном меню терминала.
- Кнопка с домиком остаётся доступной поверх страниц модов и возвращает в главное меню. При закрытии страницы восстанавливается штатное поведение кнопки.
- Оформление переключателя экранов адаптировано к новому терминалу.

Сборка и короткая игровая проверка основных сценариев прошли успешно. Для модулей используйте WolfCore 0.2.6.
